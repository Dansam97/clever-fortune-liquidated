A make.fun entry for [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c): a single fortune-cookie line written for a crypto trader who has just been liquidated. The program writes one line to `entry.txt` in the output directory — an oracular fortune whose punchline turns the chartist's "support level" into the one consolation a wiped-out portfolio still offers. The line is validated in-program against the competition gate (at most 20 words, 1–160 characters of UTF-8 text) before it is written.

## Run it

```sh
python3 main.py
```

This writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
